# 002-user-auth 模块规格说明（spec.md）

> 模块名称：用户认证模块（User Authentication）
> 所属项目：tpl-app-web（tpl-workspace 用户侧 Web 应用）
> 文档类型：As-Built 需求规格（从现有代码行为提取）
> 模块范围：用户注册、用户登录、图形验证码、退出登录、会话鉴权与自动失效
> 生成日期：2026-08-12
> 父工程规格引用：需求基准见 [../../specs/002-user-auth/spec.md](../../specs/002-user-auth/spec.md)，本文档仅补充本工程（Web 前端）特有规格

## 1. 模块概述（Module Overview）

本模块为平台提供完整的用户身份入口能力，是个人中心等业务页面访问的前提。

- 面向未注册用户提供**注册**能力：收集用户名、密码、确认密码与验证码，注册成功后引导回登录页。
- 面向已注册用户提供**登录**能力：收集用户名、密码与验证码，登录成功后建立会话并进入个人中心；若用户此前尝试访问受保护页面，登录成功后回跳至原目标页面。
- 面向所有用户提供**图形验证码**服务：登录页与注册页加载时自动获取，可点击刷新，是否强制校验由服务端配置决定。
- 面向已登录用户提供**退出登录**能力：通知服务端失效会话并清理本地凭证。
- 提供**会话保护**机制：未登录用户无法访问受保护页面；会话失效（401）时自动清理本地凭证并跳转登录页。

## 2. 用户故事（User Stories）

- US-002-001：作为用户，我可以注册一个账户（用户名、密码、确认密码、验证码），以便建立我的账号。
- US-002-002：作为用户，我可以使用用户名、密码与验证码登录系统，以便进入个人中心。
- US-002-003：作为用户，我可以在两次密码输入不一致时立即看到提示，以便及时修正。
- US-002-005：作为用户，我可以点击验证码图片刷新验证码，以便在验证码难以辨认时获取新的验证码。
- US-002-006：作为用户，我可以在登录成功后自动进入个人中心；若我原本要访问个人中心等受保护页面，登录后可直接回到原目标。
- US-002-007：作为用户，我可以在共享设备上安全退出登录，以保护我的账户隐私。
- US-002-008：作为用户，当我的会话过期时，系统应自动清理凭证并引导我重新登录。

## 3. 功能需求（Functional Requirements）

### 3.1 注册

- **FR-002-001** 注册入口：系统 MUST 提供注册页面，作为注册流程的唯一入口。
- **FR-002-002** 注册表单字段：注册表单 MUST 包含用户名、密码、确认密码、验证码。
- **FR-002-004** 密码一致性校验：当确认密码非空且与密码不一致时，系统 MUST 以内联文本提示"两次输入的密码不一致"，并 SHOULD 高亮对应输入框。
- **FR-002-005** 注册必填校验：注册提交前，系统 MUST 校验用户名、密码均为必填；任一缺失时 MUST 提示"请填写完整信息"并终止提交。
- **FR-002-006** 注册验证码校验：验证码启用状态下注册提交 MUST 要求填写验证码，未填写时 MUST 提示"请输入验证码"并终止提交。
- **FR-002-007** 注册提交防重复：注册请求处理期间提交按钮 MUST 被禁用并显示进行中文案（如"注册中..."）。
- **FR-002-008** 注册成功反馈：注册成功后系统 MUST 展示"注册成功，请登录"，并 SHOULD 在约 2 秒后自动跳转至登录页。
- **FR-002-009** 注册失败反馈：注册失败时系统 MUST 展示错误信息，并 MUST 自动刷新验证码。
- **FR-002-010** 注册后不建立会话：注册成功 MUST 不自动建立登录会话，用户需返回登录页重新登录。

### 3.2 登录

- **FR-002-011** 登录入口：系统 MUST 提供登录页面；未登录用户访问受保护页面时 MUST 被重定向至登录页。
- **FR-002-012** 登录表单字段：登录表单 MUST 包含用户名、密码、验证码。
- **FR-002-013** 登录必填校验：登录提交前系统 MUST 校验用户名与密码均为必填；任一缺失时 MUST 提示"请填写完整信息"并终止提交。
- **FR-002-014** 登录验证码校验：验证码启用状态下登录提交 MUST 要求填写验证码，未填写时 MUST 提示"请输入验证码"并终止提交。
- **FR-002-015** 登录提交防重复：登录请求处理期间提交按钮 MUST 被禁用并显示进行中文案（如"登录中..."）。
- **FR-002-016** 登录成功：登录成功后系统 MUST 建立本地会话凭证，并 MUST 跳转至受保护页面；若存在回跳参数 MUST 优先回跳至原目标，否则 MUST 跳转至个人中心。
- **FR-002-017** 登录失败反馈：登录失败时系统 MUST 展示错误信息，并 MUST 自动刷新验证码。

### 3.3 验证码

- **FR-002-018** 验证码自动获取：登录页与注册页加载时系统 MUST 自动向服务端获取图形验证码。
- **FR-002-019** 验证码点击刷新：验证码图片 MUST 可点击刷新，MUST 提供替代文本与悬停提示（"点击刷新验证码"）。
- **FR-002-020** 验证码开关：系统 MUST 依据服务端返回的配置决定是否显示验证码输入区；启用时 MUST 强制输入，未启用时 MAY 隐藏验证码输入区。
- **FR-002-021** 验证码回传：登录/注册提交时 MUST 将验证码内容与其会话标识一并回传服务端。
- **FR-002-022** 验证码刷新时机：登录/注册失败后系统 MUST 自动刷新验证码。

### 3.4 会话与退出

- **FR-002-023** 会话凭证持久化：登录成功后的会话凭证 MUST 保存于浏览器本地存储，并作为后续请求的认证依据。
- **FR-002-024** 登录态派生：系统 MUST 依据本地是否存在有效会话凭证派生"已登录"状态。
- **FR-002-025** 退出登录入口：应用页头 MUST 提供退出操作（按钮文案"退出"，MUST 提供无障碍标签"退出登录"）。
- **FR-002-026** 退出登录流程：执行退出时系统 MUST 通知服务端；MUST 清理本地凭证并清除用户信息；然后 MUST 跳转至登录页。即使服务端通知失败，本地清理 MUST 仍然执行。
- **FR-002-027** 受保护页面鉴权：系统 MUST 对业务页面执行登录鉴权；未登录时 MUST 重定向至登录页，并 SHOULD 携带原目标地址作为回跳参数。
- **FR-002-028** 已登录访问访客页：已登录用户访问登录页或注册页时 MUST 被重定向至个人中心。
- **FR-002-029** 请求附凭证：系统 MUST 在发起需身份的请求时自动附带当前会话凭证。
- **FR-002-030** 会话自动失效：当服务端返回会话未授权时系统 MUST 清理本地凭证并跳转至登录页。

## 4. 关键实体（Key Entities）

- **用户身份信息（User Identity）**：已登录用户的基础档案，包含用户标识、用户名、昵称、手机号、邮箱、生日。
- **认证会话凭证（Auth Credential）**：登录成功后由服务端签发、客户端保存并回传的凭证。
- **登录请求（Login Request）**：登录接口的入参（用户名、密码、验证码内容与验证码会话标识）。
- **注册请求（Register Request）**：注册接口的入参。
- **登录结果（Login Result）**：登录接口的出参，包含会话凭证与凭证类型。
- **验证码会话（Captcha）**：图形验证码会话，包含启用开关、会话标识与图片数据。

## 5. 验收场景（Acceptance Scenarios）

- **AS-001** 正常注册：填写全部必填字段，两次密码一致，验证码正确 → 注册成功，显示成功提示，约 2 秒后跳转登录页。
- **AS-002** 密码不一致：确认密码与密码不同 → 内联提示"两次输入的密码不一致"，输入框高亮，提交被阻止。
- **AS-003** 必填缺失：用户名或密码未填提交 → 提示"请填写完整信息"。
- **AS-004** 正常登录：用户名、密码、验证码均正确 → 建立会话，跳转个人中心；带回跳参数时跳转原目标。
- **AS-005** 登录失败：凭证或验证码错误 → 显示服务端错误信息，验证码自动刷新。
- **AS-006** 验证码刷新：点击验证码图片 → 展示新验证码，旧输入被清空。
- **AS-007** 未登录访问受保护页面：直接访问个人中心 → 重定向至登录页，携带原目标地址；登录成功后回到个人中心。
- **AS-008** 已登录访问访客页：已登录状态下访问登录页/注册页 → 重定向至个人中心。
- **AS-009** 退出登录：点击页头"退出" → 服务端会话失效，本地凭证与用户信息被清除，跳转登录页。
- **AS-010** 会话失效（401）：持有失效凭证发起请求 → 本地凭证被清除并跳转登录页。

## 6. 非功能需求（Non-Functional Requirements）

### 6.1 安全
- 系统 MUST 将图形验证码作为登录与注册的防自动化手段，并支持服务端全局开关。
- 系统 MUST 在会话失效时立即清理本地凭证，避免凭证残留。
- 退出登录 MUST 同时执行服务端失效与本地清理，本地清理 MUST 不依赖服务端成功。

### 6.2 可用性
- 登录与注册页之间 MUST 提供清晰的切换入口链接。
- 所有表单校验与操作反馈 MUST 以简体中文呈现。
- 服务端错误信息 MUST 透传展示；网络异常时 MUST 显示友好兜底提示。

### 6.3 可访问性
- 验证码图片 MUST 提供替代文本。
- 纯图标操作（退出按钮）MUST 提供无障碍标签。
- 系统 MUST 支持键盘焦点可见性。
- 系统 MUST 尊重"减少动态效果"系统偏好。
- 字段错误提示 MUST 以文本形式呈现，不得仅依赖颜色传达。

### 6.4 响应式
- 登录/注册页面 MUST 适配移动端与桌面端。
- 页面文档语言 MUST 声明为简体中文（zh-CN）。

### 6.5 性能
- 登录/注册页加载时 SHOULD 及时获取验证码，缩短用户等待。
- 页面级组件 SHOULD 按需加载（懒加载）。

## 7. 依赖（Dependencies）

- 后端认证服务：本模块 MUST 依赖后端认证接口提供验证码获取、注册、登录、退出能力。
- 验证码基础设施：验证码的生成、存储与消费由后端承担；前端仅展示与回传。
- 浏览器本地存储：会话凭证 MUST 持久化于浏览器本地存储。
- 路由鉴权基础：受保护页面鉴权、访客页隔离与登录回跳依赖路由守卫能力。
- 其他模块：登录成功后的默认落点（个人中心）属于 002-profile 模块页面。

## 8. 待确认事项（NEEDS CLARIFICATION）

1. [NEEDS CLARIFICATION] 用户档案（昵称、用户标识）在登录后未从任何接口加载填充——当前仅存在清除路径与预留的设置接口，未发现获取用户资料的调用。需明确用户资料获取时机与来源接口。
2. [NEEDS CLARIFICATION] 登录结果包含凭证类型字段（如"Bearer"），但当前请求认证头以原始凭证直传、未按其添加前缀。需确认生产环境认证头的最终格式约定。
3. [NEEDS CLARIFICATION] 会话失效跳转路径为硬编码的登录页地址，未带应用上下文路径前缀，与部署时应用挂载的上下文路径不一致。需确认生产环境路径处理方式。

## 微信登录集成

> 需求基准见父工程 [../../specs/002-user-auth/spec.md](../../specs/002-user-auth/spec.md) §11，技术设计见 `docs/002-用户注册及登录设计-微信登录集成.md`（§8.3）。本端实现完全参考 RuoYi-Vue-Plus-UI。

### 用户故事

- US-002-009：作为用户，我可以在登录页点击「微信登录」，通过微信扫码完成登录，无需输入账号密码。

### 功能需求

- **FR-002-031** 微信登录入口：登录页 MUST 提供「微信登录」按钮，受编译开关 `VITE_APP_WECHAT_LOGIN_ENABLED` 控制（默认禁用）。
- **FR-002-032** 授权跳转：点击微信登录 MUST 调用 `GET /auth/binding/wechat_open` 获取授权 URL（source 固定 `wechat_open`），整页跳转至微信扫码页。
- **FR-002-033** 回调处理：`/social-callback` 路由 MUST 读取 `code/state/source`；无 token 时调用 `socialLogin`（`POST /auth/login` grantType=social），有 token 时调用 `socialCallback`（`POST /auth/social/callback`）完成绑定。
- **FR-002-034** 登录成功落点：回调成功后 MUST 存储 token 并跳转至 `/profile`。
- **FR-002-035** 回调路由可达性：`/social-callback` MUST 在未登录（登录）与已登录（绑定）两种状态下均可达（不加 `meta.guest`）。
- **FR-002-036** 未绑定处理：后端返回业务码 `2001`（未绑定）时 SHOULD 引导用户先手机号登录后在个人中心绑定。

### 关键实体

- **社交登录请求（SocialLoginParams）**：`clientId`、`grantType='social'`、`source`、`socialCode`、`socialState`。
- **授权回调页（SocialCallback）**：读取 query 参数 `code/state/source`，无 token 走登录、有 token 走绑定。

### 编译开关

- `VITE_APP_WECHAT_LOGIN_ENABLED`（.env，默认 `false`）：关闭时隐藏微信按钮、不注册回调路由。

## 无密码账号（微信一键登录自动建号）

微信一键登录自动建号的账号无密码（`sys_user.password` 为空），Web 端处理：

- **密码登录**：不允许空密码（无密码账号无法密码登录，后端返回「该账号未设置密码，请使用微信登录」）。
- **修改密码页**：进入时调用 `GET /system/user/isEmptyPassword`；若为无密码账号，隐藏「当前密码」表单项，提交时当前密码传空字符串。

## 验证码开关（禁用验证码）

- tpl-app-api 提供图形验证码开关配置项 captcha.enable。
- captcha.enable: false（禁用）时：后端跳过验证码校验、GET /auth/code 返回 captchaEnabled: false、本端隐藏图形验证码表单项并禁用相关功能。
- 详见父工程需求基准 specs/002-user-auth/spec.md §10。
