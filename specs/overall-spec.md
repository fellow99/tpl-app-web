# tpl-app-web 整体规格说明（Overall Specification）

> 项目：tpl-app-web（tpl-workspace 用户侧 Web 应用）
> 版本：1.0.0
> 日期：2026-08-22

---

## 1. 系统概述

tpl-app-web 是 "tpl-workspace" 多端业务应用框架的用户侧 Web 前端工程，基于 **Vue 3 + Vite + TypeScript** 构建的单页应用（SPA）。

当前交付范围为最小可行产品（MVP）：系统向用户提供账户注册、登录 / 退出、以及个人中心三大基础能力，为用户账号体系与页面框架的建立提供基础。

### 1.1 目标用户

- **用户**：使用应用注册账号、登录系统、管理个人信息

### 1.2 系统范围

**在范围内**：
- 用户注册（用户名 + 密码 + 验证码）
- 用户登录（用户名 + 密码 + 验证码，支持微信登录）
- 用户登出
- 个人中心（查看/修改个人信息、修改密码）
- 应用外壳（导航守卫、HTTP 客户端、设计令牌）

**不在范围内**：
- 业务域特定功能（由框架使用方扩展）

## 2. 用户故事

### 2.1 用户认证

- 作为用户，我可以注册一个账户（用户名、密码、确认密码、验证码），以便建立我的账号。
- 作为用户，我可以使用用户名、密码与验证码登录系统，以便进入个人中心。
- 作为用户，我可以在两次密码输入不一致时立即看到提示，以便及时修正。
- 作为用户，我可以点击验证码图片刷新验证码，以便在验证码难以辨认时获取新的验证码。
- 作为用户，我可以在登录成功后自动进入个人中心；若我原本要访问受保护页面，登录后可直接回到原目标。
- 作为用户，我可以在共享设备上安全退出登录，以保护我的账户隐私。
- 作为用户，当我的会话过期时，系统应自动清理凭证并引导我重新登录。

### 2.2 个人中心

- 作为用户，我可以查看我的个人信息（昵称、手机号、邮箱、生日）。
- 作为用户，我可以修改我的个人信息。
- 作为用户，我可以修改我的密码。

## 3. 功能需求

### 3.1 用户注册

- **FR-002-001** 注册入口：系统 MUST 提供注册页面，收集用户名、密码、确认密码与验证码。
- **FR-002-002** 密码一致性校验：确认密码 MUST 与密码一致，不一致时 MUST 立即提示。
- **FR-002-003** 注册必填校验：注册提交前，系统 MUST 校验用户名、密码均为必填；任一缺失时 MUST 提示"请填写完整信息"并终止提交。
- **FR-002-004** 验证码刷新：用户 SHOULD 可点击验证码图片刷新验证码。

### 3.2 用户登录

- **FR-002-005** 登录表单：登录表单 MUST 包含用户名、密码、验证码。
- **FR-002-006** 登录成功：登录成功后系统 MUST 建立本地会话凭证，并 MUST 跳转至受保护页面；若存在回跳参数 MUST 优先回跳至原目标，否则 MUST 跳转至个人中心。
- **FR-002-007** 微信登录：系统 SHOULD 支持微信扫码登录（受编译开关控制，默认禁用）。

### 3.3 会话管理

- **FR-002-008** 登出：用户登出后系统 MUST 清除本地凭证并跳转至登录页。
- **FR-002-009** 会话过期：会话过期时系统 MUST 自动清理凭证并引导用户重新登录。
- **FR-002-010** 已登录访问访客页：已登录用户访问登录页或注册页时 MUST 被重定向至个人中心。

### 3.4 个人中心

- **FR-002-011** 信息展示：个人中心 MUST 展示当前用户信息（昵称、手机号、邮箱、生日）。
- **FR-002-012** 信息修改：系统 MUST 支持修改个人信息（昵称、邮箱、生日）。
- **FR-002-013** 密码修改：系统 MUST 支持修改密码。

---

## 4. 非功能需求

- **NFR-001** 安全：密码 BCrypt 存储、JWT 认证、AES+RSA 传输加密。
- **NFR-002** 可访问性：表单控件 SHOULD 提供可见标签；字段错误提示 MUST 以文本形式呈现。
- **NFR-003** 响应式：系统 SHOULD 在桌面与移动端均可用。
- **NFR-004** 性能：页面初始加载 SHOULD 在合理时间内完成。

---

## 5. 系统依赖

- 系统 MUST 依赖后端 API 服务（[tpl-app-api](../tpl-app-api/README.md)，Spring Boot 4.1 / Java 21，端口 8082）提供全部业务能力：验证码获取、注册、登录、退出、个人中心数据。
- 后端规范文档见 [tpl-app-api/specs/](../tpl-app-api/specs/README.md)。
